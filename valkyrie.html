Signal path — flowchart

SENSE → PROCESS → PROTECT → TRANSMIT → VISUALIZE

01 · SENSE
Cell & sensors
Voltage, current and temperature sampled from the 18650 cell via the INA219 sensor and NTC thermistor.
02 · PROCESS
Virtual MCU
Coulomb counting estimates state of charge; identical packet schema is HIL-ready for real STM32 firmware.
03 · PROTECT
Fault logic
Thresholds on voltage and temperature trigger the protection MOSFET and assert a fault flag.
04 · TRANSMIT
WebSocket stream
JSON telemetry packets are pushed in real time from the FastAPI backend to connected clients.
05 · VISUALIZE
This dashboard
Waveforms, gauges and the circuit view render each packet live, with no polling.
